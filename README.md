## Aplicación de mis conocimientos

No me basta con saber que una tecnología existe: me interesa saber en qué situaciones conviene usarla. Esto es lo que representa cada una para mí.

- **Python:** lenguaje flexible, central en ciencia de datos e IA. Lo empleé en mi proyecto de Tetris con Pygame, donde unió la programación con el álgebra lineal.
- **Java:** lenguaje orientado a objetos, adecuado para sistemas estables. Lo usé con Android Studio en el Sistema de Gestión de Hospital.
- **SQL:** lenguaje para consultar y administrar bases de datos relacionales; es el punto de partida de mi interés en bases de datos avanzadas.
- **MongoDB:** base de datos NoSQL basada en documentos, pensada para información que no encaja en tablas rígidas.
- **R:** lenguaje dedicado al análisis estadístico y a la visualización de datos, que utilizo desde RStudio.
- **JavaScript:** el lenguaje que da vida a las páginas web y la base sobre la que se apoyan TypeScript y React.
- **TypeScript:** versión de JavaScript con tipos definidos, que reduce errores y facilita mantener el código.
- **React:** librería para armar interfaces a partir de componentes que se pueden reutilizar.
- **Vite:** herramienta que acelera el arranque y la compilación de proyectos frontend.
- **Tailwind CSS:** framework de estilos con clases utilitarias, útil para diseñar interfaces con rapidez.
- **HTML y CSS:** definen la estructura y la apariencia de un sitio. Los apliqué en la página de Las Peñas.

## Proyectos

### Sistema de Gestión de Hospital

Aplicación creada para atender los problemas más habituales en el manejo de un hospital.

**Herramientas usadas:** Java y Android Studio.

**Qué incluye:**

- Una solución enfocada en las dificultades más comunes de la gestión hospitalaria.
- Desarrollo en Java dentro de Android Studio.
- Manejo de excepciones para que la aplicación siga funcionando cuando ocurre un error.
- Datos guardados en el propio dispositivo, para poder consultarlos más tarde.

**Aprendizajes:** aprendí a diseñar un sistema estable, que no se caiga ante fallos. Comprendí por qué es importante prever situaciones inesperadas con las excepciones, comprobar cómo responde el programa y conservar la información para recuperarla. Además, afiancé Java y el desarrollo de apps con Android Studio.

**Tipo de trabajo:** individual.

[Código en GitHub](https://github.com/marsuazo/Proyecto_Parcial1_Grupo_7)

### Solución del juego Tetris

Programa en Pygame que determina la mejor ubicación para no perder en Tetris.

**Herramientas usadas:** Python y Pygame.

**Qué incluye:**

- Cálculo de la posición más conveniente para cada jugada, con el fin de no perder.
- El álgebra lineal aplicada a un problema de programación.
- Simulación del juego en Python y Pygame para analizar las jugadas posibles.
- Un ejemplo práctico y visual de cómo se combinan matemáticas y código.

**Aprendizajes:** aprendí a emplear el álgebra lineal en Python para entender cómo funciona el juego. Vi cómo los conceptos matemáticos de clase se transforman en herramientas para resolver un problema concreto, y gané soltura con Python y Pygame.

**Tipo de trabajo:** individual.

[Ver repositorio](https://github.com/martinsuazob26-ui/Proyecto-algebra/upload)
